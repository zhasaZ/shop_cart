# SRS 9 — Launcher Icon и тестирование Flutter-приложения

## Как запустить (один раз)
1. Распакуйте архив, откройте папку `shop_cart` в терминале.
2. Создайте платформенные папки: `flutter create .`
3. `flutter pub get`
4. Сгенерируйте иконку: `dart run flutter_launcher_icons`
5. Запустите тесты: `flutter test`
6. Запустите приложение: `flutter run` (и сделайте скриншот иконки на главном экране эмулятора).

## Что сделано
- **Иконка:** `assets/icon/app_icon.png` (корзина на синем фоне), настройка в конце `pubspec.yaml`
  (`flutter_launcher_icons`). Добавлена адаптивная иконка Android (`adaptive_icon_background`, `adaptive_icon_foreground`).
- **Unit Test** (`test/cart_test.dart`, 10 тестов): пустая корзина, добавление, повторное добавление,
  общая стоимость, удаление, скидка, некорректные данные (скидка, пустое имя, отрицательная цена, нулевое количество), очистка.
- **Widget Test** (`test/widget_test.dart`, 6 тестов): главный экран, кнопка добавления, два товара,
  кнопка удаления, оформление пустой корзины (SnackBar), переход на второй экран и возврат.

## Ответы на контрольные вопросы
1. **Launcher Icon** — иконка приложения на главном экране и в списке приложений.
2. **flutter_launcher_icons** — автоматически генерирует иконки всех нужных размеров для Android и iOS из одного PNG.
3. Настраивается в файле **pubspec.yaml** (секция `flutter_launcher_icons`).
4. **Unit Test** — проверка отдельной функции, метода или класса без интерфейса.
5. Unit Test проверяет логику (результат вычислений), Widget Test — интерфейс (отображение и взаимодействие: кнопки, текст, поля).
6. **expect()** — сравнивает фактический результат с ожидаемым; если не совпали, тест падает.
7. **test()** — объявляет один модульный тест: описание и функция с проверками.
8. **testWidgets()** — объявляет виджет-тест; даёт объект `tester` для запуска виджетов, нажатий и обновления кадра.
9. **flutter test** — находит и запускает все тесты в папке `test/` и показывает результат.
10. Чтобы найти ошибки до пользователей, не сломать старый функционал при изменениях и снизить стоимость исправлений.
